# Simple respawn

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Simple Respawn is a Fabric mod focused on configurable lives and respawning. The goal is to let server owners shape how costly death is and give players ways to help each other get back into the game.

## Planned features

- Configure how many lives players have.
- Configure life regeneration.
- Set timers that control when players can respawn.
- Let a player sacrifice a configurable item to bring another player back. The required item should be selectable rather than fixed to a totem, so it can be replaced with any item.

This mod is in early development; these features describe its goals and may not be implemented yet.
